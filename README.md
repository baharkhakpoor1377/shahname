# قصه‌های شبانه شاهنامه

Adding a story: upload these files with the next free number (for example 10):

- `10.m4a` the voice (or .mp3)
- `10.txt` the title on the first line, then the story text
- `10.jpg` the cover picture (optional)
- `10-cards.txt` flashcards, one per line: question | answer | short explanation (optional)

The highest number appears as the cover story. Vercel rebuilds the site automatically.
